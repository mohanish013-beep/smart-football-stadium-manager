# 🏟️ FIFA 2026 Smart Stadium Command Hub & Copilot

An enterprise-grade, high-contrast **Cyber-Athletic** dashboard designed for stadium operations managers and football fans during the FIFA World Cup 2026. Built with **React**, **Tailwind CSS**, and powered by **Google Gemini AI**, the platform delivers real-time stadium insights, AI-assisted fan support, crowd management tools, and emergency response capabilities through a modern command center interface.

# ✨ Key Features

## 🏟️ Multi-Venue Live Dashboard

Monitor multiple FIFA World Cup venues through a centralized command center.

* Live stadium occupancy and capacity metrics
* Real-time venue telemetry
* Interactive live match ticker with scores and match time
* Supports major venues including:

  * Estadio Azteca
  * MetLife Stadium
  * SoFi Stadium

---

## 🤖 Gemini AI Fan Copilot

An intelligent virtual assistant powered by **Google Gemini 1.5 Flash**.

### Features

* Multilingual fan assistance
* Context-aware responses
* AI-powered navigation guidance
* Smart recommendation chips including:

  * 🍔 Fast Food Path
  * 🚻 Clean Restrooms
  * 🚪 Main Exit
  * 🅿️ Parking Assistance

---

## 🗺️ Interactive Stadium Navigation

A responsive SVG-based tactical stadium map that provides real-time navigation.

### Highlights

* Live destination routing
* Animated path visualization
* Interactive navigation vectors
* Mobile-friendly responsive layout

---

## ⚙️ What-If Operations Simulation

A decision-support module for stadium administrators.

Simulate operational scenarios such as:

* Crowd congestion
* Turnstile failures
* Gate rerouting
* Capacity balancing
* Emergency evacuation planning

This helps operators evaluate responses before implementing them in real-world situations.

---

## 🚨 Emergency SOS Incident Console

A dedicated emergency management dashboard featuring:

* Live incident monitoring
* Emergency broadcast system
* Pulse-animated alert notifications
* Timestamped incident logs
* Rapid response controls
